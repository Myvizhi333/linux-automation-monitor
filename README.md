Linux Automation & Monitoring System

1) Project Description
   This project is a simple Linux monitoring tool created using a shell script.
   It checks system information like CPU usage, memory usage, disk usage, and system uptime.

2) Features
  * CPU usage monitoring
  * Memory usage monitoring
  * Disk space checking
  * System uptime display
  * Simple automation using shell script

3) Technologies Used
  * Linux
  * Bash Shell Script

4) How to Run
    1. Clone the repository
    2. Navigate to the project folder
    3. Run the script

   ```
      chmod +x monitor.sh
      ./monitor.sh
   ```
